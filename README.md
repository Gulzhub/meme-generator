# Meme Generator — React App

A simple and interactive meme generator built with React that allows users to create custom memes using random images and personalized text.
Here's the [live link](https://gulzhub.github.io/meme-generator/)
---

## 🚀 Key Highlights

* Built with **React**
* Integrated **Imgflip API** to fetch meme templates
* Managed **form state and user input efficiently**
* Dynamically updates UI based on user actions
* Clean and responsive design

---

## 🛠️ Tech Stack

React • JavaScript (ES6+) • HTML • CSS • REST API

---

## ⚙️ Core Functionality

* Fetches a list of meme images from an API
* Displays a random meme image on button click
* Allows users to add top and bottom text
* Updates meme preview in real time

---

## 🔗 API

https://api.imgflip.com/get_memes
